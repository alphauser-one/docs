It is possible to create API Keys to connect with other systems.&#x20;

For example, you might have a news bulletin service you may want to broadcast to your homepage. In order to do this, create the API key and connect the service to the system via webhooks.

Please note that it may be necessary to develop API end points for this purpose. Please contact us for further information.

To create API Keys, click on your name at the top right hand corner of the homepage will display a personal profile.
![](/images/personalprofile.png)

In the personal profile will be a tab for 'API Keys'. Click on 'manage API keys' to create  any api keys necessary. To suck all the air out of.
